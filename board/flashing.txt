Setup Environment
=================

sudo dnf install pipx
pipx ensurepath
source ~/.bashrc
pipx --version
pipx install esptool
pipx install mpremote
esptool version
mpremote --version

Erase the entire flash
----------------------
esptool erase-flash

Flash Micropython
-----------------
esptool --port /dev/ttyACM0 --baud 460800 write-flash 0 ESP32_GENERIC_C3-20260824-v1.29.0.bin

Test Micropython
----------------
mpremote connect /dev/ttyACM0 repl
